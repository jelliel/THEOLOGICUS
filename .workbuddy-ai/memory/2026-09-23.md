## Diagnostic TTS — le vrai defaut de prononciation (mesure)

**Contexte.** Demande : ajouter ElevenLabs, ou mieux, un moteur comme

**La video n'a AUCUN audio** : `volumedetect` → `mean_volume: -91.0 dB`,
`max_volume: -91.0 dB`, histogramme entierement sur le seau -91 dB. C'est une
capture d'ecran muette. On ne peut donc pas diagnostiquer a l'oreille ; les
images montrent en revanche l'app avec panneaux Coran (arabe + traduction FR)

**Sonde ecrite** : `.workbuddy-ai/artifacts/_tts/probe_voices.js` (CDP + `ws`,
sert `THEOLOGICUS.html` depuis la racine). 23 voix exposees sur cette machine.

### Ce que la sonde a mesure

```
AUCUNE voix hebreu. AUCUNE voix grecque ancienne. AUCUNE voix latine.
ar-SA : Microsoft Naayf - Arabic (Saudi)   <- SEULE voix non-latine utile

Resolution de l'app :
  francais -> Google francais (fr-FR)
  arabe    -> Microsoft Naayf (ar-SA)      <- OK
  hebreu   -> Google francais (fr-FR)      <- DEFAUT
  grec     -> Google francais (fr-FR)      <- DEFAUT
```

### La cause racine (deux defauts qui se composent)

1. **`getVoiceForLang()` a un repli francais `return`-ant, pas `null`.**
   Quand le prefixe de langue n'a aucune voix (`he`, `el`), le code ne sort pas
   : il **tombe dans les paliers fr-FR** (l. ~14572-14587) et **retourne la voix
   francaise**. Or `makeUtterance` teste `if (v)` pour decider du repli
   phonetique (l. 14883) : `v` etant la voix FR, la branche
   `transliterateForSpeech()` **n'est JAMAIS atteinte**. Le mot hebreu est lu
   par une voix francaise — soit saute, soit baragouine. **Tout le mecanisme de
   repli phonetique (l. 14721-14775, `_HE_PHON`, `_HE_VOWEL`, `_EL_PHON`) est
   du code mort sur cette machine.**
   -> `hebreu` et `grec` sont tous deux resolus en `fr-FR` alors qu'aucune voix
   hebraique/grecque n'existe.

2. **`VOICE_FALLBACK` n'est pas consultable par `getVoiceForLang`.**
   La table existe (l. 14499) mais la fonction n'y entre jamais par ce chemin.

3. **La segmentation perd la virgule des references francaises.**
   `splitByLanguage('Exode 24:12 ...')` produit **trois** segments :
   `"Exode 24:"`, `"12"`, puis l'hebreu. La pause entre « 24 » et « 12 » coupe
   la reference en deux (« Exode vingt-quatre » / « douze »). Idem
   `"Coran 20:"` + `"12"`. **C'est le defaut de prononciation des REFERENCES**,
   distinct du defaut hebreu.

**Mode de lecture courant mesure : `fr` (francais force)** — donc tout ce qui
n'est pas script non-latin est lu en francais, et les scripts non-latins
retombent sur le defaut n°1.
